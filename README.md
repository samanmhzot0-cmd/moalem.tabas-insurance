# سامانه بیمه — نسخه Full Stack

این پروژه نسخه نمایشی Full Stack سامانه بیمه است.

## امکانات
- ثبت‌نام و ورود امن‌تر با JWT
- هش کردن رمز عبور با bcrypt
- پروفایل هر کاربر
- ثبت درخواست انواع بیمه
- مشاهده درخواست‌های شخص
- آپلود چند عکس برای بیمه بدنه
- ذخیره اطلاعات در فایل JSON برای نسخه آزمایشی

## اجرا

نیاز به Node.js دارد.

```bash
npm install
npm start
```

سپس:
http://localhost:3000

## نکته امنیتی مهم
این پروژه برای نمونه و توسعه اولیه است. برای محیط واقعی باید:
- JWT_SECRET در متغیر محیطی تنظیم شود.
- دیتابیس واقعی مثل PostgreSQL/MySQL استفاده شود.
- HTTPS فعال شود.
- کنترل دسترسی نقش‌ها برای مدیر اضافه شود.
- محدودیت‌های آپلود و اسکن فایل سخت‌گیرانه‌تر شود.
- اطلاعات حساس مطابق الزامات قانونی نگهداری شود.
- تعرفه‌ها و فرایند صدور به سامانه رسمی شرکت متصل شوند.
